# Thiranex E-Commerce Full Stack Project

Complete e-commerce project for the Thiranex Task 3 assignment.

## Features
- Product catalog, search and category filter
- Add to cart and checkout
- User registration and login
- JWT authentication and bcrypt password hashing
- User order history and order status
- Admin product management
- Admin order management
- MongoDB database
- Responsive frontend

## Tech stack
HTML, CSS, JavaScript, Node.js, Express.js, MongoDB, JWT, bcryptjs.

## Run
1. Install Node.js and MongoDB.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Create `.env` from `.env.example`.
5. Start with `npm start`.
6. Open `http://localhost:5000`.

Demo admin from `.env.example`: admin@example.com / Admin@12345. Change it before public deployment.

Never upload `.env` to GitHub. `.gitignore` already excludes it.
